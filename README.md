\# Библиотека



Учебный проект (курсовая работа по МДК.01.01 «Разработка программных модулей»): информационная система учёта выдачи изданий в библиотеке учебного заведения.



\*\*Автор:\*\* Д. С. Блинова, группа 324, специальность 09.02.07 «Информационные системы и программирование».

\*\*Тема:\*\* «Разработка информационной системы для библиотеки учебного заведения».

\*\*Руководитель:\*\* Т. Т. Дуларидзе.



\## Назначение

Настольное приложение заменяет бумажные журналы: электронный каталог с поиском, бронирование, выдача, продление и возврат изданий, автоматический контроль сроков, отчёты о выдачах и должниках.



\## Версии

\- C#, .NET 10

\- Avalonia UI 12.1.3

\- Entity Framework Core 10.0.12 (Database First)

\- Microsoft SQL Server 2025 Express

\- Среда разработки: Visual Studio



\## Роли

\- \*\*Гость:\*\* каталог изданий, поиск, фильтр по жанру, сортировка.

\- \*\*Читатель:\*\* бронирование, отмена брони, продление выдачи (один раз на 7 дней), «Мои выдачи».

\- \*\*Библиотекарь:\*\* подтверждение брони, выдача, возврат, картотека читателей, фонд и экземпляры, отчёты (выдачи за период, должники, сохранение в CSV).

\- \*\*Администратор:\*\* роли пользователей, справочники (жанры, группы, издательства).



\## Правила

До 5 записей на руках, выдача на 14 дней, одно продление на 7 дней, бронь хранится 3 дня и затем отменяется автоматически, при просроченном издании новая бронь недоступна.



\## Ограничения учебного входа

Вход учебный: пароли тестовых учётных записей простые и приведены ниже, смена пароля в программе не реализована. В базе пароли хранятся в виде хеша SHA-256. Подключение к базе выполняется через Windows-аутентификацию, логин и пароль SQL Server в репозитории не хранятся.



\## Состав папок

\- `Assets` — логотип, значок и обложки изданий.

\- `Data` — подключение к базе данных (контекст Entity Framework).

\- `Database` — SQL-скрипт создания и заполнения базы.

\- `Docs` — пояснительная записка, протокол тестирования, презентация.

\- `Models` — классы моделей, созданные по базе данных.

\- `Services` — бизнес-правила и проверка прав (`LoanService`, `LoanManager`, `CatalogService`, `StaffService`, `Session`).

\- `Views` — страницы и главное окно (Avalonia).



\## Последовательность SQL-файлов

Нужен один скрипт: `Database/LibraryDB\_create.sql`. Он создаёт базу LibraryDB, таблицы, ограничения и заполняет их тестовыми данными (20 изданий, 45 экземпляров, 15 пользователей, 25 выдач). Скрипт можно запускать повторно: старая база пересоздаётся.



\## Настройка connection.txt

Файл `connection.txt` содержит строку подключения. По умолчанию:

`Server=localhost\\SQLEXPRESS;Database=LibraryDB;Trusted\_Connection=True;Encrypt=True;TrustServerCertificate=True;Connect Timeout=5`

Если у вас другое имя сервера, замените `localhost\\SQLEXPRESS` на своё.



\## Запуск

1\. Установить .NET 10 SDK, SQL Server Express и SSMS.

2\. Выполнить `Database/LibraryDB\_create.sql` в SSMS.

3\. Проверить `connection.txt`.

4\. Открыть `LibraryApp.csproj` в Visual Studio и нажать F5, либо в папке проекта выполнить:

&#x20;  `dotnet run`



Тестовые учётные записи: `admin` / `admin123`, `librarian1` / `lib123`, `reader01` … `reader12` (пароль совпадает с логином).
