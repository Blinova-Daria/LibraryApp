# Библиотека

Учебный проект: информационная система учёта выдачи изданий (курсовая работа).
Настольное приложение на C# (.NET 10, Avalonia UI 12.1.3, Entity Framework Core 10.0.12) и база данных Microsoft SQL Server.

## Возможности
- Гость: каталог изданий, поиск, фильтр по жанру, сортировка.
- Читатель: бронирование, отмена брони, продление выдачи (один раз на 7 дней), «Мои выдачи».
- Библиотекарь: подтверждение брони, выдача, возврат, картотека читателей, фонд и экземпляры, отчёты (выдачи за период, должники, CSV).
- Администратор: роли пользователей, справочники (жанры, группы, издательства).
- Бронь, не востребованная за 3 дня после подтверждения, отменяется автоматически.

## Запуск
1. Установить SQL Server Express и SSMS.
2. Выполнить `Database/LibraryDB_create.sql` в SSMS (создаёт базу LibraryDB и тестовые данные).
3. Проверить строку подключения в `connection.txt`.
4. Открыть `LibraryApp.csproj` в Visual Studio и нажать F5.

Тестовые учётные записи: `admin` / `admin123`, `librarian1` / `lib123`, `reader01` ... `reader12` (пароль = логин).
